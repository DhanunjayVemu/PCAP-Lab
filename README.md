# PCAP-Lab
Parallel Computer Architecture and Programing (PCAP) Lab programs 
(An Integrated lab component in the CSE3129 course at MIT, Manipal)

## Abstract Syllabus:
Implement shared memory programs using OpenMP; Implement distributed memory programs 
using MPI; Implement GPU programs using CUDA.
